# Student Registration WebApp

A comprehensive web-based application designed to streamline the student registration process. This system allows administrators to manage student records, track enrollments, and maintain an organized database efficiently.

## Features
*   **User Authentication:** Secure login and registration system.
*   **Student Dashboard:** Manage student profiles, view enrolled courses, and update personal details.
*   **Admin Panel:** Full CRUD (Create, Read, Update, Delete) access to manage student records from the database.
*   **Responsive Design:** Optimized layout for seamless use across both desktop and mobile devices.

## Installation and Setup

To run this project locally, follow these steps:

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/snaddans/Student-Registration-WebApp.git](https://github.com/snaddans/Student-Registration-WebApp.git)
    ```

2.  **Navigate to the project directory:**
    ```bash
    cd Student-Registration-WebApp
    ```

3.  **Open the project:**
    Launch the folder in VS Code or your preferred code editor.

4.  **Set up the environment:**
    *   Configure your database connection settings in the configuration file.
    *   Import the provided database schema (if applicable).
    *   Install any necessary backend dependencies.

5.  **Run the application:**
    Start your local development server and open the `index.html` (or localhost port) in your browser.

## Usage
1.  Navigate to the application URL.
2.  Use the registration form to add a new student, filling out all required academic and personal details.
3.  Submit the form to securely save the data to the backend system.
4.  Use the dashboard to view, edit, or remove existing student entries.
